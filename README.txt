# Market Expansion case study files

Copy these files into your existing GitHub Pages portfolio.

- `index.html` — updated home page with the new case study
- `case-study-market-expansion.html` — new case study page
- `style.css` — existing styling plus case-study styles
- `assets/hospital-expansion-explorer.html` — interactive map/explorer
- `assets/hospital-expansion-data.js` — portfolio data + simplified ZIP geometry

The explorer uses Leaflet and OpenStreetMap tiles via CDN. Google Analytics uses the existing measurement ID and the parent case-study page tracks explorer events via `postMessage`.
